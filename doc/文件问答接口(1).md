# 文件问答接口文档

## 接口概述

- **接口名称**: `http://ip:port/document_question_answer`
- **调用方式**: POST
- **Content-Type**: `application/json`
- **接口描述**: 当用户上传一个或多个文件且输入框有问题或要求时，应用端将文件解析为纯文本后调用本接口，服务基于文件内容回答用户问题。接口支持流式和非流式两种输出模式，内部统一使用流式生成链路；当 `stream=false` 时，服务端消费完整流式结果后返回 JSON。

## 请求参数

| 参数名 | 参数类型 | 必填 | 说明 | 示例 |
|---|---|---|---|---|
| documents | array[object] | 是 | 文件文本列表，长度 1-50 | 见示例 |
| documents[].file_name | string | 否 | 文件名，用于多文件上下文标识；为空时服务端使用 `文件N` | `档案1.pdf` |
| documents[].text | string | 是 | 应用端解析后的纯文本，不能为空字符串 | `故宫博物院...` |
| query | string | 是 | 用户输入框中的要求或问题，不能为空 | `请总结文件中的关键信息` |
| answer_max_length | int | 否 | 回答长度参考上限，默认 `document_question_answer.answer_max_length`，范围 100-2000 | `800` |
| stream | bool | 否 | 是否使用 SSE 流式输出，默认 `false` | `true` |

## 非流式响应

当 `stream=false` 或未传时，返回 JSON：

```json
{
  "code": 200,
  "message": "success",
  "answer": "根据已上传文件，故宫博物院旧称紫禁城，位于北京市中心，是明清两代皇家宫殿。"
}
```

## 流式响应

当 `stream=true` 时，响应类型为 `text/event-stream`。`answer` 事件返回模型正文增量，`result` 事件返回最终结构化结果：

```text
data: [START]

data: {"type":"answer","value":"根据已上传文件，"}

data: {"type":"answer","value":"故宫博物院旧称紫禁城。"}

data: {"type":"result","value":{"code":200,"message":"success","answer":"根据已上传文件，故宫博物院旧称紫禁城。"}}

data: [DONE]
```

可能出现的事件类型：

| type | 说明 |
|---|---|
| answer | 模型正文增量 |
| reason | 模型思维增量，仅在启用思维链且模型返回时出现 |
| result | 最终结构化结果 |
| error | 流式生成中的错误 |

参数错误发生在生成前，仍返回普通 JSON 400。

## 请求示例

```json
{
  "documents": [
    {
      "file_name": "故宫简介.txt",
      "text": "故宫博物院，旧称紫禁城，位于北京市中心，是明清两代的皇家宫殿。"
    },
    {
      "file_name": "建筑规模.txt",
      "text": "故宫占地面积72万平方米，建筑面积约15万平方米。"
    }
  ],
  "query": "请根据文件内容总结故宫的基本情况",
  "answer_max_length": 500,
  "stream": false
}
```

## 异常响应示例

```json
{
  "code": 400,
  "message": "参数错误：query 不能为空"
}
```

```json
{
  "code": 400,
  "message": "参数错误：stream 须为布尔值"
}
```

## 注意事项

1. 本接口不接收二进制文件，只接收应用端解析后的纯文本。
2. 回答 Prompt 约束模型只能依据文件内容回答；文件中没有依据时返回“根据已上传文件未找到相关信息。”。
3. 输入内容统一按 `llm.max_input_tokens` 做 token 预算，服务会保留固定提示词、用户问题和输出要求，只截断文件正文。
4. 本期不返回结构化引用来源；如需 `references` 字段，需要补充接口契约。
