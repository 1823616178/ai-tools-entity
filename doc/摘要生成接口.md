# 摘要生成接口文档

## 接口概述

- **接口名称**: `http://ip:port/summary_generation`
- **调用方式**: POST
- **Content-Type**: `application/json`
- **接口描述**: 接收一组文本内容，按顺序拼接后生成一段摘要。接口支持流式和非流式两种输出模式，内部统一使用流式生成链路；当 `stream=false` 时，服务端消费完整流式结果后返回 JSON。

## 请求参数

| 参数名 | 参数类型 | 必填 | 说明 | 示例 |
|---|---|---|---|---|
| text_list | array[string] | 是 | 待生成摘要的文本列表，长度 1-50 | 见示例 |
| max_length | int | 否 | 摘要最大字数参考值，默认 `summary.max_length`，范围 50-500 | `200` |
| stream | bool | 否 | 是否使用 SSE 流式输出，默认 `false` | `true` |

## 非流式响应

当 `stream=false` 或未传时，返回 JSON：

```json
{
  "code": 200,
  "message": "success",
  "summary": "故宫博物院位于北京市中心，旧称紫禁城，是明清两代皇家宫殿。"
}
```

## 流式响应

当 `stream=true` 时，响应类型为 `text/event-stream`。事件格式：

```text
data: [START]

data: {"type":"answer","value":"故宫"}

data: {"type":"answer","value":"博物院位于北京市中心"}

data: {"type":"result","value":{"code":200,"message":"success","summary":"故宫博物院位于北京市中心，旧称紫禁城，是明清两代皇家宫殿。"}}

data: [DONE]
```

可能出现的事件类型：

| type | 说明 |
|---|---|
| answer | 模型正文增量 |
| reason | 模型思维增量，仅在启用思维链且模型返回时出现 |
| result | 最终结构化结果 |
| error | 流式生成中的错误 |

参数错误发生在生成前，仍返回普通 JSON 400。

## 请求示例

```json
{
  "text_list": [
    "故宫博物院，旧称紫禁城，位于北京市中心，是中国明清两代的皇家宫殿。",
    "故宫占地面积72万平方米，建筑面积约15万平方米。"
  ],
  "max_length": 200,
  "stream": false
}
```

## 异常响应示例

```json
{
  "code": 400,
  "message": "参数错误：text_list 不能为空"
}
```

```json
{
  "code": 400,
  "message": "参数错误：stream 须为布尔值"
}
```

## 注意事项

1. `text_list` 内各条文本会按列表顺序拼接后整体处理。
2. 输入内容统一按 `llm.max_input_tokens` 做 token 预算，服务会保留固定提示词和输出要求，只截断可截断正文。
3. `max_length` 是提示模型控制摘要长度的参考值，不能保证输出字数精确等于该值。
